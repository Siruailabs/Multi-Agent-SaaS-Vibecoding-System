
# Siru SaaS Starter

A reusable Multi-Agent Vibecoding system for building scalable SaaS projects.

## Included
- AGENTS.md
- RULES.md
- Project Context
- Prompt Templates
- SaaS Folder Structure

## Recommended Stack
- Next.js
- TypeScript
- TailwindCSS
- PostgreSQL
- Prisma
- Redis
- Vercel
- Railway

## Usage

Paste this into your AI IDE:

Read AGENTS.md, RULES.md, and docs/project-context.md.

Act as the Main Agent.

Before coding:
1. Understand the product
2. Break the feature into tasks
3. Assign work to the correct subagent
4. Generate only one module at a time
5. Review before continuing
