
# SaaS Project Rules

## Agent Workflow
1. Product Agent → planning
2. Main Agent → architecture
3. Database Agent → schema
4. Backend Agent → logic
5. UI Agent → design
6. Frontend Agent → screens
7. QA Agent → testing
8. Deploy Agent → launch

## Core Rules
- Never build without a plan
- Never write backend before schema
- Never write frontend before API contract
- Never hardcode secrets
- Always use TypeScript
- Always add validation
- Always test before deploy
- Build one feature at a time
