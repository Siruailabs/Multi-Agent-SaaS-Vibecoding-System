
# Multi-Agent SaaS Vibecoding System

## Main Agent = CEO / Architect
Responsibilities:
- System architecture
- Task orchestration
- Code review
- Scalability
- Security
- Feature planning

## Product Agent = Planning
Responsibilities:
- MVP scope
- User stories
- Pricing
- Business logic
- Roadmap

## UI Agent = Design
Responsibilities:
- SaaS layouts
- Design system
- Responsive UI
- UX optimization

## Frontend Agent = Screens
Responsibilities:
- Next.js pages
- Components
- State management
- API integration

## Backend Agent = Logic
Responsibilities:
- APIs
- Auth
- Business logic
- Queues
- Integrations

## Database Agent = Schema
Responsibilities:
- PostgreSQL schema
- Prisma models
- Indexing
- Query optimization

## QA Agent = Testing
Responsibilities:
- Unit tests
- Integration tests
- Security validation
- Edge case testing

## Deploy Agent = Launch
Responsibilities:
- CI/CD
- Monitoring
- Deployment
- Scaling
- Production optimization

# Workflow

Idea → Planning → DB → Backend → Frontend → Testing → Deploy
